# Papua Explorer Interactive
<img width="1897" height="902" alt="image" src="https://github.com/user-attachments/assets/ff3b6074-c6ac-4fd2-b9ab-6dcdb89884a9" />


Aplikasi web interaktif yang menampilkan keindahan Papua dengan tema desain
mengikuti identitas Visit Papua.


## Tech stack

- [TanStack Start](https://tanstack.com/start) (React + TanStack Router, SSR)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/) components (Radix UI primitives)

## Development

Butuh Node.js (atau Bun) terpasang.

```sh
git clone <url-repo-ini>
cd papua-explorer-interactive
npm i
npm run dev
```

Perintah lain yang tersedia:

```sh
npm run build     # build untuk production
npm run preview   # preview hasil build
npm run lint      # jalankan eslint
npm run format    # rapikan format kode dengan prettier
```
